# Unresolved manuscript-to-code issues

Review date: 2026-09-20. These are limitations of the supplied source, not proof that the biological findings are false.

1. **Dominant-program provenance.** The included 6,165-cell continuous usage argmax disagrees with frozen final labels in 602 cells, including 256 changes of P1 membership. Argmax P1 count is 1,753; final labels/manuscript give 1,857. Projection overwrites fitted-subset NNLS usages with consensus usages, whereas Methods describes highest projected usage. Missing fitted objects prevent validation of that rule. Do not relabel cells automatically. Supply the authoritative final usage, per-cell assignment source and projection provenance.
2. **Cell-selection pipeline.** Classification applies existing CNV/entropy metrics. Frozen inclusion checks do not implement QC, doublet removal, Harmony, annotation, CNV/entropy inference, epithelial-purity and final squamous-lineage selection. The 10,856-to-6,165 reduction needs its actual rules and inputs.
3. **scFEA.** The validator's incorrect P1-versus-P5 reference has been corrected for the P1-versus-non-P1 comparison. M80 d=0.995787084361 for the latter; P1-versus-P5 d=1.282050443614. The historical 25-row source table is P1 versus P5 and is NOT the current S2C source. Current S2C displays 25 modules, while its legend says all 168. The complete correct contrast table is included, but the final displayed subset selection, plotting code and original scFEA inference pipeline are missing.
4. **TF analysis.** The manuscript says decoupler v2.1.5 ULM; supplied code implements custom ULM/MLM equations without calling decoupler. Its expression background is the target union of 18 focused TFs. It pools both methods and both priors for BH correction per contrast. The scale of the missing malignant h5ad X and the primary Figure 2F correction family require confirmation. Mathematical similarity is not established package equivalence.
5. **Missing computational implementations.** Figure 1E top100 pseudobulk overlap; Figure 3A paired test; Figure 5A-B usage-tertile expression proxies; S1C balanced 600-cell heatmap; S3C exact-CXCL10 score-removal comparison; S5A grouped dependency comparison; Figure 5D/S5B bootstrap confidence intervals; and several final plotting layouts are absent. Supplying only similar scores is insufficient.
6. **S3C definition.** Methods says standardized SLC3A2 alone; Results still says SLC3A2-only residual; the image says SLC3A2 alone. A residual requires a specified regression. Confirm the actual score and provide source code before recreating this panel.
7. **Branch sensitivity.** Raw-count scoring supports usage-argmax and h5ad labels; scaled scoring uses usage-argmax. Confirm that S2A used identical cells and labels so normalization is the only changed factor. Positive z-scaled expression is not a raw-count detection rate.
8. **External validation.** TCGA staging specifies Xena HiSeqV2 while the manuscript names GDC. The exact aliquot-selection implementation and Figure 4E median-trend bootstrap are absent. DepMap score standardization occurs across all expression models before selecting the 57 HNSCC models; BH covers 20 tests. Full external analyses were not rerun in this preparation.
9. **Clinical/experimental materials.** Figure 4A-D, Figure 5E-H, S4A, S5E and Table 1 require clinical or laboratory source materials outside this code archive. The antibody/reagent Supplementary Table cited in Methods is absent from the two supplied documents. Table 1 categorical totals are internally consistent, but patient-level source data are needed to verify age and other values.
