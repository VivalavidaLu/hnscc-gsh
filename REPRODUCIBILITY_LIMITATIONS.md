# Reproducibility limits

This candidate supports source inspection, frozen-data checks, and selected analysis branches with staged external inputs. It is not a complete manuscript reproduction.

Read [KNOWN_ISSUES.md](KNOWN_ISSUES.md) for scientific discrepancies, [MANUSCRIPT_CODE_MAP.md](MANUSCRIPT_CODE_MAP.md) for every panel/table, [WORKFLOW.md](WORKFLOW.md) for inputs and dependencies, and [REPRODUCTION_CHECK.md](REPRODUCTION_CHECK.md) for executed versus historical checks.

The frozen cell manifest verifies membership and counts, not the complete filtering process. Included continuous usage and final labels disagree; neither has been silently replaced. Original source measurements are required to verify clinical and experimental results. Final plot code is missing for several computational panels.

Large matrices are excluded. Some derived h5ad construction steps are also missing. Public accession links do not substitute for these transformations. Full analysis requirements differ from the manuscript's reported environment and were not freshly installed as a complete set.
